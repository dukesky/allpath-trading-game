# Bagholder Simulator 🥬 (韭菜模拟器)

A 3-minute browser game from the [AllPath Trading Agent](https://trading.all-path.com): you get $10,000 and a
hidden slice of **real market history**, read the news each round, and decide to sell, hold, go all in or
YOLO on margin. At the end the era is revealed and you're scored against doing nothing, "Panic Pete" (the
classic retail pattern) and a rules robot (40-week trend filter) that never panics.

Play: **https://trading.all-path.com/game** · English and 中文 · not financial advice.

## Scenarios

Nine hidden scenarios, each with three assets (S&P 500, Nasdaq-100, and one "spicy" stock revealed at the end):
dot-com bubble, 2008 GFC, 2020 COVID crash, 2022 rate hikes, 2018 trade war, 2021 meme stocks, the calm 2017
bull + crypto mania, the 2025 tariff shock, and an ordinary 10% correction (2023). Headlines describe what was
in the news at each decision date with names blurred; prices are real weekly closes (split/dividend adjusted).

## Develop

```bash
npm install
npm run dev        # http://localhost:5174/trading/game/
npm test           # engine + scenario integrity tests
npm run sim        # scripted players through every scenario (balance check)
```

- `src/engine.ts` – portfolio math, margin calls, benchmarks, titles (pure)
- `src/game.ts` – game state on top of the engine (pure)
- `src/scenarios.ts` – scenario scripts (bilingual)
- `src/data/prices.json` – generated by `uv run --with yfinance --with pandas python scripts/fetch_data.py`
- `scripts/gen_art.py` – cartoon art via OpenRouter (`art/raw/*.png`, converted to `public/art/*.webp`)

## Deploy

The game is a static build served by the AllPath website (Next.js on Cloud Run):

```bash
scripts/sync-to-site.sh ../allpath   # builds and copies dist/ into ../allpath/public/trading/game/
```

then commit and deploy the site repo as usual. `trading.all-path.com/game` is routed there by the site's
middleware and a rewrite in its `next.config.ts`.
